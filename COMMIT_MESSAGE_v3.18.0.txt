v3.18.0 - Template Editor Bug Fixes + Preview-to-Editor Cursor Sync

🐛 CRITICAL BUG FIXES:

1. **Pink Color Tint Bug (FIXED)**
   - Issue: After closing template editor modal, entire app had pink overlay/tint
   - Root Cause: Modal backdrop-filter interaction with body::before and ::after pseudo-elements
   - Solution: Force browser repaint using transform translateZ(0) + requestAnimationFrame
   - Files Modified: closeEditor() function at line ~2325
   - Result: Theme colors now perfectly preserved after modal close

2. **Info Box Insert Bug (FIXED)**
   - Issue: Info box insertion didn't work properly in editable preview
   - Root Cause: insertInfoBox() only handled textarea, not contenteditable preview
   - Solution: Detect focus context (preview vs editor) and handle both insertion methods
   - Files Modified: insertInfoBox() function at line ~2480
   - Result: Info box now inserts correctly in both code editor and live preview

🎯 NEW FEATURE:

3. **Preview-to-Editor Cursor Sync (IMPLEMENTED)**
   - Feature: Click any element in live preview → editor scrolls and positions cursor
   - Implementation:
     * Added syncPreviewClickToEditor() function
     * Maps clicked preview element to HTML code location
     * Calculates approximate line number for smooth scrolling
     * Highlights editor background briefly for visual feedback
   - Files Modified: New function block at line ~2610
   - Result: Instant, accurate cursor positioning from preview to code
